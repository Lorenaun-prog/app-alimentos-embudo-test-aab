# 🍎 Análisis de Comportamiento de Usuarios y Test A/A/B — Aplicación Alimenticia

Nota: Proyecto del programa Data Analyst, con datos de un caso práctico.

## 📌 Contexto

Análisis de datos de interacción de usuarios para una aplicación de productos alimenticios, enfocado en:

Entender el embudo de ventas y la conversión de usuarios.

Evaluar un test A/A/B sobre cambios de diseño de la aplicación (fuentes) para medir su impacto en el comportamiento de los usuarios.

## 🔎 Objetivos

Limpiar y preparar los datos de eventos de usuario.

Analizar la frecuencia y secuencia de eventos para identificar pérdidas en el embudo de conversión.

Comparar grupos de control (A/A) y prueba (B) para determinar si las fuentes alteradas afectan la interacción.

Evaluar la significancia estadística de diferencias observadas entre grupos.

Recomendar decisiones basadas en evidencia sobre el diseño de la aplicación.

## 📂 Datasets

logs_exp_us.csv → eventos de usuarios: nombre de evento, ID de usuario, timestamp y grupo experimental (246, 247 control; 248 prueba).

## 🛠️ Tecnologías

Python · pandas · numpy · matplotlib · seaborn · scipy · Jupyter Notebook
